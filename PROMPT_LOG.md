# Промпт-лог (История работы с ИИ)

Команда: 3 (КИБ-03)
Проект: Сигнал — тренажер для HR-специалистов

## Хронология запросов к ИИ-платформам

Шаг 1. Генерация структуры
*   Промпт: «Мне нужно создать веб-приложение (квиз) для HR. Оно должно показывать видео и предлагать два вопроса: что видно/слышно и какое действие выбрать. Напиши базовую структуру HTML (index.html) и стили (style.css)».
*   Результат: ИИ сгенерировал базовую верстку и CSS. Мы приняли каркас, но решили изменить цвета на более корпоративные (зеленый/серый).

Шаг 2. Написание логики (JavaScript)
*   Промпт: «Напиши логику на JS. Нужно, чтобы пользователь не мог нажать кнопку "Проверить", пока не выберет оба варианта ответа. И чтобы в конце выводился результат из 6 баллов (3 за наблюдение, 3 за действие)».
*   Результат: ИИ написал скрипт. Изначально кнопка "Проверить" была активна всегда, мы попросили ИИ добавить атрибут disabled и функцию проверки.

Шаг 3. Наполнение контентом
*   Промпт: «Добавь в массив cases три сценария: подмена звука, сбой связи и звонок без камеры. Для каждого пропиши текст, варианты ответов и правильный выбор».
*   Результат: ИИ сгенерировал массив. Пришлось вручную поправить тексты, чтобы они звучали как реальные диалоги HR.

Шаг 4. Тестирование
*   Промпт: «Как сделать так, чтобы после прохождения квиза можно было начать его заново?»
*   Результат: ИИ предложил функцию очистки массива answers и сброса индекса index. Принято.
